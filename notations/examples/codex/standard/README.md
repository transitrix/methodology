# `STANDARD` — externally issued technical standard

An ISO-shaped `STANDARD` artefact in `codex/external/intl/`. The TYPE is for a
document a **standards-developing organisation** issues (ISO, IEC, IEEE, and
peers) — not a statute (`LAW`), not a regulation issued under a statute
(`REGULATION`), and not a convention the adopting organisation writes for
itself (`INTERNAL_STANDARD`). A regulation that incorporates this standard by
reference stays a `REGULATION` and cites the `STANDARD`.

```
codex/external/intl/STANDARD-iso-27001-1.yaml
```

See [`../../../elements/14-codex.md`](../../../elements/14-codex.md) §1.1, §2, §2.2.
The `intl` jurisdiction folder is live (not reserved). `CODEX-001` still
requires the folder name to match `jurisdiction:`.
